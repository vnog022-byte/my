# Super Mario Bros. — Mundo 1-1

Recriação do Mundo 1-1 em HTML5 Canvas, num único arquivo (`index.html`), sem dependências além da fonte *Press Start 2P* do Google Fonts.

## Como jogar

Abra o `index.html` no navegador.

| Ação   | Teclado                  | Celular |
|--------|--------------------------|---------|
| Mover  | ← → (ou A / D)           | ◀ ▶     |
| Pular  | Z, Espaço, ↑ (ou W / K)  | A       |
| Correr | X, Shift (ou J)          | B       |

Ao completar a fase, aperte Enter ou toque na tela para jogar de novo.
